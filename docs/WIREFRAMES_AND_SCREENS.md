# Raaga (ರಾಗ) — App Screens & Wireframes Specification

Raaga uses a Karnataka-inspired aesthetic combining **Kumkuma Maroon (`#800020`)**, **Mysore Gold (`#D4AF37`)**, and **Saffron (`#FF9933`)**, supporting both **Dark OLED Mode** and **Mysuru Silk Light Mode**, with instant runtime switching between **ಕನ್ನಡ (Kannada)** and **English**.
